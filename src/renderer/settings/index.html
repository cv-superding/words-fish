通用设置

开机自启

登录 Windows 后自动启动（默认最小化到托盘）。

启动时最小化到托盘

开启后只显示托盘图标，不弹出设置窗口。

关闭按钮最小化到托盘

关闭按钮只隐藏窗口，不退出进程。

托盘显示今日计数

在托盘悬浮提示里显示今日看过的单词数。

打开数据目录

查看 / 备份 config.json、records.json、自定义词库。
